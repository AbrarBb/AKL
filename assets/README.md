# Portfolio Media Assets Guide

Place your recorded project videos, logos, and screenshots in this folder to display them in the portfolio modal:

### 1. Recorded Videos (`assets/videos/`)
Drop your `.mp4` video files here with these filenames:
- `citygo.mp4` (or `.webm`)
- `noyza.mp4`
- `cyvia.mp4`
- `synaptalk.mp4`
- `pragmaguard.mp4` (also embeds your live YouTube demo)
- `zkpvote.mp4`

*(If a file is not yet present, the portfolio automatically displays a high-fidelity video player preview with full technical case study, screenshots, and live/demo links!)*

### 2. Project Logos (`assets/logos/`)
Drop your project logo PNG/SVG files here:
- `citygo-logo.png`
- `noyza-logo.png`
- `cyvia-logo.png`
- `synaptalk-logo.png`
- `pragmaguard-logo.png`
- `zkpvote-logo.png`
