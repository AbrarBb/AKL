# AKL — Abrar Khatib Lajim Portfolio

Personal portfolio website of **Abrar Khatib Lajim** — Creative Developer, CS Student at East West University, and Systems/Security Researcher based in Dhaka, Bangladesh.

## Tech Stack
- **HTML5 & Vanilla CSS3**: Custom design system, responsive bento grid, dark aesthetic, smooth micro-interactions.
- **JavaScript (ES6+)**: Custom particle canvas, smooth scroll reveal, counter animations, interactive magnetic elements.
- **Devicon & Lucide Icons**: High-fidelity vector tech stack iconography.

## Features
- Interactive hero with real-time particle grid canvas
- Bento grid showcasing background, scholarship, and focus
- Experience & education timeline
- Selected work with live demo and source code links
- Research Interests matrix across Smart Contract Security, Zero-Knowledge Proofs, Machine Learning, and HCI
- Full responsive design (Desktop, Tablet, Mobile)
- Custom cursor & dynamic typewriter
