# AKL - Abrar Khatib Lajim Portfolio

Personal portfolio website of **Abrar Khatib Lajim** - Final-year Computer Science & Engineering student at East West University, founder of **Khatib Studio** (indie Android development), and researcher in smart contract security based in Dhaka, Bangladesh. Expected graduation: Fall 2026.

## About
My work spans two primary tracks:
1. **Indie Android Apps**: Shipping production applications end-to-end under Khatib Studio to the Google Play Store (offline-first architecture, acoustic signal telemetry, clean UX).
2. **Security & Cryptography Research**: Investigating smart contract forensic auditing, anti-rug-pull heuristics, and zero-knowledge privacy protocols supervised by faculty.

Comfortable across Java/Android, Flutter, Python, LaTeX, and technical document/report generation. Twice awarded the **Medha Lalon Scholarship** for academic excellence.

## Featured Projects
- **CityGo**: Multi-role public transit and fleet management ecosystem built as a passenger/admin/driver web app ([AbrarBb/citygo](https://github.com/AbrarBb/citygo)) plus a companion Flutter supervisor mobile app ([AbrarBb/citygo-supervisor](https://github.com/AbrarBb/citygo-supervisor)).
- **Noyza**: Production Android app under Khatib Studio evaluating ambient noise and environment suitability in real time, published on the Google Play Store ([AbrarBb/Noyza](https://github.com/AbrarBb/Noyza)).
- **Cyvia**: Offline-first Android cycle and health tracker under Khatib Studio, published on the Play Store. Full prediction functionality with zero network dependency, ensuring strict data privacy ([AbrarBb/Cyvia](https://github.com/AbrarBb/Cyvia)).
- **Synaptalk** (Capstone): AI-based assistive communication system using real-time eye tracking to help individuals with limited mobility communicate. Paved with deliberate engineering trade-offs, cutting an initial BCI scope to focus on a high-precision vision gaze model ([AbrarBb/Prototype-1-February](https://github.com/AbrarBb/Prototype-1-February)).
- **PragmaGuard**: Supervised research forensic tool auditing rug-pull risks across 3,324 verified Ethereum contracts using NLP intent extraction, static bytecode AST analysis, and ensemble ML ([AbrarBb/PragmaGuard](https://github.com/AbrarBb/PragmaGuard)).
- **ZKPVote**: Privacy-preserving blockchain e-voting prototype demonstrating Zero-Knowledge Proofs and Homomorphic Encryption for verifiable secret ballots.
